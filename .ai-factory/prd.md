# EnlistPay

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
입대 예정자와 현역 장병을 위한 전역일 D-day 계산과 계급별 월급·휴가 적립 현황을 한눈에 보여주는 앱

## Problem
입영 대상자·현역 장병이 전역일 계산, 계급별 월급 인상 시점, 휴가 일수를 여러 사이트에서 따로 찾아야 하고 매년 인상되는 병사 월급 반영이 번거로움

## Target Users
입영 예정 20대 남성, 현역 장병, 장병 가족

## Core Features
1. 입대일 입력 시 전역일 D-day 자동 계산
2. 계급별(이병~병장) 월급 자동 계산 및 진급일 알림
3. 정기·포상 휴가 적립 현황 관리
4. 전역 후 목돈 마련 적금 시뮬레이션
5. 매일 확인하는 D-day 위젯 화면
6. 급여 누적 총액 상세 계산 리워드 광고 게이팅

## Monetization
- Model: ads
- Estimated MRR: ₩337,000/월 (약 $250)
- Reasoning: D-day 확인 습관으로 매일 배너 노출이 발생하고, 급여 누적 총액 등 상세 정보는 리워드 광고로 게이팅
