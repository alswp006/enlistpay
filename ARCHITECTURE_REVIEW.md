# Architecture Review
Generated: 2026-09-06T22:47:01.097Z
Score: 72/100

## Summary
The codebase has a clean layered structure (domain/storage/components/pages) with well-documented 'pre-built' UI primitives and a consistent PageShell/ScreenScaffold pattern, but it suffers from significant copy-paste duplication of small utilities (haptics, Chip type-bridging, vacation sorting/flags defaults) that were never consolidated into the hooks/components already created for that purpose. There is also a real type-naming collision (`PayTable`) between the domain layer and the auto-generated contract layer, two competing storage abstractions, and inconsistent state-management (most app state flows through AppDataProvider, but savings input bypasses it). No circular import chains were found among the reviewed files.

## Issues
### Critical
- [duplication] An identical `fireHaptic(type: "success" | "tickWeak")` helper (try/catch around `generateHapticFeedback`) is redefined locally in five different files instead of using the existing `useHaptic` hook, which itself is never imported anywhere. — Files: src/components/BottomCTA.tsx, src/components/VacationFormSheet.tsx, src/pages/Onboarding.tsx, src/pages/Savings.tsx, src/pages/Settings.tsx, src/hooks/useHaptic.ts / Fix: Delete the local fireHaptic copies, extend useHaptic to cover both haptic types (with the Promise.resolve().catch() pattern used elsewhere), and import it everywhere haptics are fired.
- [naming] `PayTable` is declared twice with completely incompatible shapes: `src/domain/types.ts` defines it as `{ year, monthlyPay: Record<Rank,number>, annualLeaveDays, defaultServiceMonths }` while `src/lib/contract.ts` defines it as `{ [rank: string]: { base: number; allowance: number } }`. Anyone grepping for `PayTable` or relying on the contract file's documentation will get the wrong shape. — Files: src/domain/types.ts, src/lib/contract.ts / Fix: Rename the contract-layer type (e.g. `ContractPayTable`) or remove it if the domain type already supersedes it, and reconcile the contract file with what was actually implemented.
